# DB Quest + SQL Quest

Corsi gamificati di **progettazione di database** (DB Quest) e **SQL** (SQL Quest) per l'ITES Valturio di Rimini.

- `index.html` — l'intera applicazione (una sola pagina, nessuna installazione).
- `firestore.rules` — regole di sicurezza da pubblicare in Firebase Console → Firestore → Regole.

Finché in `index.html` la configurazione Firebase (blocco `CONFIG.firebase`) è vuota, il sito funziona in **modalità demo**:
login simulato e progressi salvati solo nel browser di chi lo usa.
